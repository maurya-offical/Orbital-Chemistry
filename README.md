Orbital Chemistry – Online Chemistry Learning Platform

Orbital Chemistry is a web-based educational platform designed to make chemistry learning easier, more interactive, and accessible for students preparing for Class 11, Class 12, JEE, and NEET examinations.

The platform provides a centralized learning environment where students can explore chemistry courses, access video lessons, practice questions, take mock tests, track their learning progress, and enroll in courses online.

It includes student authentication, course management, an administrative dashboard, coupon management, and online payment functionality through Razorpay. The platform also provides a contact system for students to ask questions and receive support.

Key Features

Student Authentication: User registration, login, and password management.

Course Management: Browse courses and enroll in selected courses.

Video Learning: Access educational video lessons.

Practice & Mock Tests: Practice questions and prepare for competitive examinations.

Student Dashboard: Monitor learning activities and progress.

Online Payments: Secure course purchases through Razorpay integration.

Coupon Management: Apply promotional discounts during course purchases.

Admin Dashboard: Manage courses, students, enrollments, coupons, orders, and contact messages.

Contact Support: Students can submit questions and inquiries.

Technologies Used

Frontend: HTML, CSS, JavaScript

Backend: Java, Spring Boot

Database: MySQL (if configured)

Backend Security: Spring Security, JWT

ORM: Spring Data JPA / Hibernate

Build Tool: Maven

Payment Gateway: Razorpay

Project Objective

The primary objective of Orbital Chemistry is to create a digital learning platform that combines structured educational content, online assessments, student management, and secure course purchasing into one application.

Project Type: Full-Stack Web Application
Domain: E-Learning / EdTech
